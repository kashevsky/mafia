# Документация - resources/js/game/game.js

## Обзор
JavaScript модуль, реализующий игровую логику мафии для фронтенда. Управляет стадиями игры, голосованиями, ночными действиями ролей и сохранением состояния.

## Константы

### GAME_STAGES
Определяет все стадии игры:
- **NIGHT_KNOWING (10)**: Мафия знакомится
- **CHOOSE_FIRST_PLAYER (0)**: Выбор первого игрока для дневного голосования
- **DAY_VOTE (1)**: Дневное голосование
- **VOTE_RESULT (2)**: Результат голосования
- **ROULETTE_CONFIRM (3)**: Рулетка - подтверждение
- **ROULETTE_PLAY (4)**: Рулетка - игра
- **NIGHT_WAIT (5)**: Ночь - ожидание пробуждения
- **NIGHT_END (5.1)**: Ночь - выбор кого разбудить
- **MAFIA_KILL (6)**: Мафия выбирает жертву
- **MAFIA_DON (6.1)**: Дон блокирует
- **MAFIA_PRESPECHNIK (6.2)**: Приспешник компрометирует
- **PEACE_SHERIF (7.1)**: Шериф проверяет
- **PEACE_DOCTOR (7.2)**: Доктор лечит
- **PEACE_ADVOCAT (7.3)**: Адвокат дает иммунитет
- **PEACE_KARATEL (7.4)**: Каратель убивает
- **PEACE_FREDDI (7.5)**: Фредди помечает
- **PEACE_SUDYA (7.6)**: Судья накладывает вето
- **PEACE_DETECTIVE (7.7)**: Детектив проверяет
- **PEACE_BOMBA (7.8)**: Бомба ставит мины
- **PEACE_DZHURNALIST (7.9)**: Журналист проверяет
- **PEACE_STRELOCHNIK (7.11)**: Стрелочник переводит выстрел
- **PEACE_OBOROTEN (7.12)**: Оборотень
- **SKIP_VOTE (20)**: Игрок пропускает голосование (заблокирован судьей)
- **GAME_END_NIGHT (50)**: Конец игры (ночь)

### GAME_STATE_KEYS
Массив ключей для сохранения состояния в localStorage.

## Основное состояние

### Игровые переменные
- `stageGame`: Текущая стадия игры
- `users`: Массив игроков
- `countDays`: Количество дней
- `countNights`: Количество ночей
- `_quantityPossibleDoctor`: Сколько раз доктор может лечить себя (по умолчанию 2)
- `_quantityBlockDon`: Сколько раз Дон может блокировать (по умолчанию 1)
- `_quantityCheckDzhurnalist`: Сколько раз Журналист может проверять (по умолчанию 2)
- `_isActiveSkillPrespechnik`: Активен ли скилл Приспешника

### saveNightGame
Объект для хранения ночных действий:
- `idPlayerKillsTheMafia`: Кого убивает мафия
- `idPlayerBlockedTheDon`: Кого блокирует Дон
- `idPlayerBlockedThePrespechnik`: Кого компрометирует Приспешник
- `idPlayerCheckTheSherif`: Кого проверяет Шериф
- `idPlayerTherapyTheDoctor`: Кого лечит Доктор
- `idPlayerImmunityTheAdvokat`: Кому дает иммунитет Адвокат
- `idPlayerKillTheKaratel`: Кого убивает Каратель
- `idPlayerCheckTheFreddy`: Кого помечает Фредди
- `idPlayerBlockTheSudiy`: Кого блокирует Судья
- `arrIdsPlayersBlockTheSudiy`: Массив id заблокированных Судьей
- `idPlayerCheckTheDetective`: Кого проверяет Детектив
- `idPlayerKillTheDetective`: Кого убивает Детектив
- `arrIdsPlayersMinesTheBomba`: Массив id заминированных Бомбой
- `arrIdsPlayersCheckTheDzhurnalist`: Массив id проверенных Журналистом
- `arrIdsPlayerKillTheStrelochnik`: Массив id на кого перевел Стрелочник

### UI состояние
- `boardMess`: Сообщение на доске
- `nameBtn`: Название кнопки
- `messBoardAlert`: Сообщение алерта
- `activeUser`: Активный игрок

## Структура игрока (user)
```javascript
{
  id: number,
  name: string,
  nickname: string,
  role: string, // Роль (Мафия, Шериф, Доктор и т.д.)
  character: 'Y' | 'N', // Y - мирный, N - мафия
  count: number, // Количество голосов
  is_alive: 0 | 1, // Живой или мертвый
  active: 0 | 1, // Активен (чей ход)
  target: 0 | 1, // На кого голосуют
  number: number, // Номер игрока
  position: number, // Позиция за столом
  is_vote: 0 | 1, // Проголосовал или нет
  start_game: 0 | 1, // Начинает игру
  buff_role: [], // Массив бафов (кто наложил эффект)
  immunities: [] // Массив иммунитетов
}
```

## Основные методы

### Публичные методы

#### init()
Инициализация игры:
- Загружает пользователей из store
- Запускает игру через `_startGame()`
- Загружает сохраненное состояние через `_loadGameState()`

#### eventUser(id)
Обработка клика на игрока. В зависимости от стадии игры:
- Выбор первого игрока
- Выбор цели для голосования/действия
- Проверка блокировок и иммунитетов

#### eventBtn()
Обработка нажатия главной кнопки. Переключает стадии игры в зависимости от `stageGame`

#### eventVote()
Обработка подтверждения голоса/действия:
- Добавляет голос
- Сохраняет ночные действия
- Переключает на следующую роль

#### eventWakeUp(role)
Пробуждение конкретной роли ночью:
- Активирует игроков выбранной роли
- Устанавливает соответствующую стадию игры
- Сбрасывает цели

#### eventEndNight()
Завершение ночи:
- Обрабатывает все ночные действия
- Рассчитывает смерти (мафия, каратель, детектив, стрелочник, бомба)
- Проверяет иммунитет Адвоката
- Обрабатывает взрыв Бомбы
- Проверяет вето Судьи
- Сбрасывает состояние и переходит к дню

#### eventDirection(isDirection)
Выбор направления голосования (по часовой/против часовой)

#### eventFinishGame(role)
Завершение игры с указанием победителя ('мирный', 'мафия', 'ничья')

#### eventDeleteUser(id) / eventDeleteUserConfirm()
Удаление игрока админом

### Приватные методы (начинаются с _)

#### _sendDataGame()
Отправка состояния игры на сервер через AJAX на `/log-step`

#### _saveGameState()
Сохранение состояния в localStorage

#### _loadGameState()
Загрузка состояния из localStorage

#### _startGame()
Начало игры - находит живых игроков, выводит алерты

#### _checkStageGame()
Проверка и установка текста стадии игры

#### _startNight()
Начало ночи:
- Сбрасывает активных и голоса
- Подсчитывает живых
- Отмечает Стрелочника и Бомбу как проголосовавших (после 2 ночи)
- Проверяет превращение Оборотня в мафию
- Парит игроков (Каратель, Шериф, Адвокат, Детектив)

#### _pairPlayers(role)
Находит пару для роли (используется для Карателя, Шерифа, Адвоката, Детектива)

#### _oborotenBecomesMafia()
Если нет живой мафии, Оборотень становится мафией. Отправляет данные на сервер `/make-oboroten`

#### _nextUser()
Переход к следующему игроку при дневном голосовании с учетом направления

#### _calcCountVote()
Расчет голосов, определение лидеров, обработка ничьи (рулетка)

#### _toggleUserActive(id)
Активация конкретного игрока

Сброс активных игроков

Сброс целей

Сброс количества голосов

Сброс голосов

Поиск живых игроков

## Специальная логика ролей

### Мафия
- Убивает одного игрока ночью
- Оборотень просыпается вместе с мафией если character='N'

### Дон
- Блокирует роль (добавляет баф "Дон")
- Может блокировать только 1 раз за игру
- После 3 ночей не может голосовать

### Приспешник
- Компрометирует мирного игрока (добавляет баф "Приспешник")
- Может компрометировать ограниченное число раз (`_isActiveSkillPrespechnik`)
- Нельзя компрометировать Бомбу и мафию
- Если Шериф проверяет компрометированного - видит "мафия" и скилл деактивируется

### Шериф
- Проверяет игрока - видит "мирный" или "мафия"
- Если запачкан Доном - не может проверять
- Оборотень всегда показывается как "город"

### Доктор
- Лечит одного игрока ночью
- Может лечить себя только 2 раза (`_quantityPossibleDoctor`)
- Если запачкан Доном - не может лечить
- Спасает от одного выстрела (мафия, каратель, детектив, стрелочник)

### Адвокат
- Дает иммунитет игроку (добавляет баф "Адвокат")
- Не может дать иммунитет себе
- Если запачкан Доном - не может давать иммунитет
- Иммунитет работает d/n (защита от 1 дня и 1 ночи) или d/n/d (от 2 дней и 1 ночи)

### Каратель
- Убивает одного игрока ночью
- Если запачкан Доном - не может убивать
- Если стреляет в Стрелочника - Стрелочник просыпается и переводит выстрел

### Фредди (Мститель)
- Помечает игрока (добавляет баф "Фредди")
- Если запачкан Доном - не может помечать
- Если Фредди умирает ночью - помеченный игрок умирает (если мафия или Оборотень, или если запачкан Приспешником)

### Судья
- Блокирует игрока от дневного голосования (добавляет баф "Судья")
- Если запачкан Доном - не может блокировать
- Нельзя блокировать одного и того же игрока подряд
- Заблокированный игрок пропускает ход (стадия SKIP_VOTE)

### Детектив
- Проверяет игрока - видит "мирный" или "мафия"
- Если запачкан Доном - не может проверять
- Если проверяет того же игрока дважды - может убить если мафия
- Если проверяет компрометированного Приспешником - видит "мафия", скилл Приспешника деактивируется
- Оборотень всегда "город"

### Бомба
- Ставит мины на 25% живых игроков ночью
- После 2 ночей не может голосовать
- При смерти:
  - Если есть мины - взрывает заминированных
  - Если первый день - убивает 25% ближайших соседей
- Мины сбрасываются на вторую ночь

### Журналист
- Проверяет 2 игроков за ночь
- Может проверять только 2 раза за игру (`_quantityCheckDzhurnalist`)
- Если запачкан Доном - не может проверять
- Если на него есть выстрел (Мафия, Каратель, Стрелочник) - теряет шанс
- После 2 проверок сообщает "одна команда" или "разные команды"
- Оборотень всегда "город"

### Стрелочник
- Переводит выстрел на другого игрока
- Если запачкан Доном - не может действовать
- Если в него стреляют (Мафия или Каратель) - просыпается и переводит выстрел
- Может переводить только если не запачкан Доном

### Оборотень
- character='Y' (показывается как мирный)
- Если вся мафия погибла - становится мафией (character='N')
- Мафия не убивает Оборотня если у него нет бафа "Дон"
- Всегда показывается как "город" для Шерифа, Детектива, Журналиста

## Система бафов (buff_role)
Массив строк на игроке, указывающих кто наложил эффект:
- "Мафия" - выбран мафией для убийства
- "Дон" - заблокирован Доном
- "Приспешник" - компрометирован Приспешником
- "Шериф" - проверен Шерифом
- "Доктор" - вылечен Доктором
- "Адвокат" - иммунитет Адвоката
- "Каратель" - выбран Карателем
- "Фредди" - помечен Фредди
- "Судья" - заблокирован Судьей
- "Детектив" - проверен Детективом
- "Детектив-убийца" - убит Детективом
- "Бомба" - заминирован Бомбой
- "Журналист" - проверен Журналистом
- "Cтрелочник" - на него перевел Стрелочник

## Система иммунитетов
Объект immunities на игроке:
```javascript
{
  type: 'd/n' | 'd/n/d', // Тип иммунитета
  title: string,
  pivot: {
    is_active: 0 | 1
  }
}
```

- `d/n`: Защита от 1 дня и 1 ночи
- `d/n/d`: Защита от 2 дней и 1 ночи

Проверяется в `checkImmunities(user)` - возвращает true если иммунитет активен и еще не истек по дням/ночам.

## Таймер
Метод `timer(isActive)`:
- Запускает таймер с отображением ММ:СС
- После 50 секунд добавляет класс `timer-red`
- После 300 секунд (5 минут) останавливается

## Сохранение состояния
Все ключи из `GAME_STATE_KEYS` сохраняются в localStorage при каждом изменении через `_saveGameState()`.

При загрузке проверяется совпадение `tableId` - если отличается, состояние не загружается.

## AJAX запросы
- `/log-step` - отправка состояния игры
- `/change-role` - изменение роли Приспешника
- `/make-oboroten` - превращение Оборотня в мафию
- `/kill-player` - удаление игрока (через store)
