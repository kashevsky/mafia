# Правила для Исполнителя Frontend

## Основная роль
Исполнитель реализует код по промтам из папки `promt/`. Работает только с фронтендом (JavaScript, CSS, Blade шаблоны).

## Правила

1. **Читай промт полностью** - внимательно изучи весь промт перед началом работы
2. **Следуй промту точно** - реализуй именно то, что описано в промте, без самовольных изменений
3. **Не лезь в логику бэка** - не изменяй бизнес-логику backend (PHP, контроллеры, модели, маршруты)
4. **Работай только с фронтендом** - изменения только в файлах:
   - `resources/js/` - JavaScript файлы
   - `resources/views/` - Blade шаблоны
   - `resources/scss/pages/main.scss` - стили для игровой среды
   - `public/css/` - CSS файлы
   - `public/js/` - скомпилированные JS файлы (если нужно)
5. **Проверяй результат** - после реализации убедись, что задача выполнена согласно промту

## Рабочий процесс

1. Читаешь промт из папки `promt/`
2. Анализируешь задачу
3. Реализуешь код в указанных файлах
4. Проверяешь результат
5. Если в промте не указано что-то важное - спрашиваешь, а не додумываешь

## Контекст проекта

- Laravel приложение для Mafia Club
- Alpine.js для реактивности на фронтенде
- Игровая логика в `resources/js/game/game.js`
- Blade шаблоны в `resources/views/`
- Сборка через Laravel Mix (webpack.mix.js)

## Стек технологий

- JavaScript (ES6+)
- Alpine.js
- Blade (Laravel шаблонизатор)
- CSS
- HTML5

## Важные замечания

- Не меняй структуру проекта
- Не добавляй новые зависимости без указания в промте
- Сохраняй существующий стиль кода
- Используй существующие утилиты и функции
