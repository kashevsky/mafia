# Инструкция для исполнителя

## Основные правила

1. **Пиши только код** - ты пишешь исключительно код по промтам, которые получаешь из директории `promt/`
2. **Не лезь в логику бэка** - не изменяй бизнес-логику backend, работай только с тем, что указано в промте
3. **Следуй промтам точно** - реализуй именно то, что описано в промте, без самовольных изменений

## Рабочий процесс

- Промты находятся в директории `promt/` в корне проекта
- Читай промт, реализуй код, не выходя за рамки задачи
- Если в промте не указано что-то важное - спроси, а не додумывай
