# Изменить логику лечения доктора для Детектива и Мстителя

## Описание проблемы
Текущая логика позволяет доктору спасать игроков от выстрела детектива и от мстителя (Фредди). Нужно изменить логику так, чтобы:
1. Детектив убивает мафию даже если её вылечит доктор
2. Мститель (Фредди) забирает мафию, которую лечит доктор - лечение игнорируется
3. Это касается только мафии - если детектив или мститель стреляют в мирного игрока, лечение доктора работает как обычно

## Требуемое поведение
- **Детектив**: лечение доктора НЕ спасает от выстрела детектива ТОЛЬКО если цель - мафия (character === 'N')
- **Мститель (Фредди)**: если цель - мафия (character === 'N'), лечение доктора игнорируется
- Если детектив или мститель стреляют в мирного игрока - лечение доктора работает как обычно

## Файлы для изменения
`resources/js/game/game.js`

## Анализ проблемы

### Текущая логика лечения доктора (строки 670-674)
```javascript
} else if (userSaveDoctor.id == userKillDetective?.id && !doctorSaved) { // Доктор спасает от выстрела детектива (если не спас никого ранее)
    this.saveNightGame.idPlayerKillTheDetective = null;
    userKillDetective = null;

    doctorSaved = true;
```
Эта проверка позволяет доктору спасать от выстрела детектива. Нужно удалить этот блок.

### Текущая логика мстителя (строки 766-800)
```javascript
// проверяем кого пометил Мститель и жив ли он
let freddy = this.findUserRole('Фредди');

if (userMarkFreddy && !freddy.is_alive) {

    if (userMarkFreddy.character === 'N' || userMarkFreddy.role === "Оборотень") {
        userMarkFreddy.is_alive = 0;
        // ... убиваем
    }
}
```
Сейчас нет проверки на лечение доктора. Нужно добавить проверку:
- Если доктор лечит того, кого пометил Фредди
- И цель - мафия (character === 'N' или role === "Оборотень")
- То лечение игнорируется, игрок все равно умирает

## Конкретное решение с кодом

### Изменение 1: Игнорировать лечение доктора для детектива при стрельбе в мафию
В методе обработки ночи (строки 670-674) изменить блок лечения от детектива:

Было:
```javascript
} else if (userSaveDoctor.id == userKillDetective?.id && !doctorSaved) { // Доктор спасает от выстрела детектива (если не спас никого ранее)
    this.saveNightGame.idPlayerKillTheDetective = null;
    userKillDetective = null;

    doctorSaved = true;
```

Стало:
```javascript
} else if (userSaveDoctor.id == userKillDetective?.id && !doctorSaved) { // Доктор спасает от выстрела детектива (если не спас никого ранее)
    // Проверяем: если цель детектива - мафия, лечение игнорируется
    if (userKillDetective.character === 'N') {
        // Не лечим мафию от детектива
        doctorSaved = false;
    } else {
        // Лечим мирного от детектива
        this.saveNightGame.idPlayerKillTheDetective = null;
        userKillDetective = null;
        doctorSaved = true;
    }
```

### Изменение 2: Игнорировать лечение доктора для мстителя при убийстве мафии
В логике мстителя (строки 766-800) нужно:

1. Убрать проверку `|| userMarkFreddy.role === "Оборотень"` из условия (строка 778)
2. Добавить проверку на лечение доктора перед убийством мафии

Было (строка 778):
```javascript
if (userMarkFreddy.character === 'N' || userMarkFreddy.role === "Оборотень") {
```

Стало:
```javascript
if (userMarkFreddy.character === 'N') {
    // Если цель - мафия, проверяем лечит ли её доктор
    if (userSaveDoctor && userSaveDoctor.id == userMarkFreddy.id) {
        // Доктор лечит мафию, но лечение игнорируется - Фредди всё равно убивает
        // Ничего не делаем, просто убиваем ниже
    }
```

Логика убийства остается прежней, но теперь явно указано что лечение доктора игнорируется для мафии.

## Шаги для выполнения

1. Открыть файл `resources/js/game/game.js`
2. Найти строки 670-674 (блок лечения от детектива)
3. Изменить блок: добавить проверку - если цель детектива - мафия (character === 'N'), лечение игнорируется
4. Найти строку 778 в логике мстителя
5. Убрать проверку `|| userMarkFreddy.role === "Оборотень"` из условия
6. Добавить проверку на лечение доктора перед убийством мафии (как показано в Изменении 2)
7. Протестировать изменения

## Контекст изменений
- Изменения касаются только ночной фазы игры
- Детектив и Мститель (Фредди) - мирные роли
- Доктор - мирная роль
- Изменения влияют на баланс игры - мафия становится более уязвимой к детективу и мстителю
