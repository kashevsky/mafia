# Задача: Дать возможность ведущему давать иммунитет до наступления первой ночи

## Описание задачи
Сейчас ведущий может дать иммунитет только в начале игры (когда `countDays === 0`). Нужно изменить условие, чтобы ведущий мог давать иммунитет до наступления первой ночи (то есть когда `countDays === 0` И `countNights === 0`).

## Анализ проблемы
1. В файле `resources/views/play.blade.php` строка 223 есть условие `<template x-if="countDays===0">`
2. Это означает, что кнопка "Дать иммунитет" показывается только когда `countDays === 0` (первый день)
3. Но если наступила первая ночь (`countNights > 0`), кнопка все еще показывается, хотя уже нельзя давать иммунитет
4. Нужно изменить условие на `countDays === 0 && countNights === 0` - первый день И еще не было ночи

## Решение
Изменить условие в `play.blade.php` с `countDays===0` на `countDays===0 && countNights===0`.

## Файлы для изменения

### `resources/views/play.blade.php`
В строке 223 изменить условие:

```blade
<template x-if="countDays===0 && countNights===0">
```

## Что сделать
1. Открой файл `resources/views/play.blade.php`
2. Найди строку 223: `<template x-if="countDays===0">`
3. Измени её на: `<template x-if="countDays===0 && countNights===0">`
4. Проверь:
   - Кнопка "Дать иммунитет" показывается в первый день до наступления ночи
   - После наступления первой ночи кнопка скрывается

## Контекст
- `countDays` - количество дней в игре
- `countNights` - количество ночей в игре
- Условие `countDays===0 && countNights===0` означает: первый день И еще не было ночи
