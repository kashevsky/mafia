# Задача: Скрыть роль Бомбы после 3 ночей с доски showModalNight

## Описание задачи
Роль Бомба должна скрываться с ночной доски (showModalNight) после 3 ночей (то есть начиная с 4-й ночи).

## Анализ проблемы
1. Роль Бомба отображается в файле `resources/views/include/modal-night/index.blade.php` в строках 326-360
2. Уже есть условие `x-show="countNights <= 2"` для прогресса бомбы (строка 341) - показывает прогресс только в первые 2 ночи
3. Нужно скрыть всю карточку роли Бомба после 3 ночей (когда `countNights > 2`)

## Решение
Добавить условие `x-show="countNights <= 2"` к всему блоку роли Бомба (строки 326-360).

## Файлы для изменения

### `resources/views/include/modal-night/index.blade.php`
В строке 326 добавить условие `x-show="countNights <= 2"` к template с ролью Бомба.

## Что сделать
1. Открой файл `resources/views/include/modal-night/index.blade.php`
2. Найди строку 326: `<template x-if="user.role == 'Бомба'">`
3. Измени её на:
   ```blade
   <template x-if="user.role == 'Бомба' && countNights <= 2">
   ```
4. Проверь:
   - В 1-ю, 2-ю, 3-ю ночь роль Бомба отображается на доске
   - Начиная с 4-й ночи роль Бомба не отображается на доске

## Контекст
- Переменная `countNights` хранит количество ночей в игре
- Условие `countNights <= 2` означает: 0, 1, 2 ночи - показывать, 3 и более ночей - скрывать
- Роль Бомба может минировать игроков только в первые 3 ночи, поэтому после 3 ночей её можно скрывать
